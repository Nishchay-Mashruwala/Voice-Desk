# Exact versions of every Python package the speech engine may install, so
# friends who install on different days get the same, tested set. Used as
#   pip install -r engine/requirements.txt -c engine/constraints.txt
# (and the same for requirements-nvidia.txt / requirements-indic.txt). The app's
# first-run setup passes -c automatically when this file exists. A constraint
# only fixes a version; it never installs anything by itself.
#
# Target: Python 3.12 (python-build-standalone) on Windows x64, macOS arm64 and
# x86_64, Linux x64. Every pin below has cp312 wheels (or a pure-Python wheel)
# for those platforms; where it doesn't, a marker picks another version.
#
# To update:
#   1. In a fresh Python 3.12 venv:
#        python -m pip install -U -r engine/requirements.txt
#        python -m pip freeze
#      Copy the versions into the "Core" section (keep the markers).
#   2. For the packs: same with requirements-nvidia.txt, and with
#      requirements-indic.txt plus
#        --index-url https://download.pytorch.org/whl/cpu --extra-index-url https://pypi.org/simple
#   3. Check each changed version has cp312 wheels for all four platforms
#      (https://pypi.org/pypi/<package>/<version>/json, or
#      pip download <pkg>==<ver> --no-deps --only-binary=:all: --python-version 3.12 --platform <tag>).
#   4. Check it resolves:
#        python -m pip install --dry-run -r engine/requirements.txt -c engine/constraints.txt
#      then run the engine tests and a real dictation + meeting before tagging.
