# Voice Desk mobile — frontend

The Flutter app: screens and widgets (`lib/ui/`), the app's start (`lib/main.dart`)
and the Android/iOS shells (`android/`, `ios/`). Recording, the database and
permissions live in [../backend](../backend), a Dart package this app depends on.

Run on a phone from this folder:

    flutter run

Tests: `flutter test` here (screens) and in `../backend` (logic).
